# playwright-tutorial

A hands-on Playwright curriculum built around **Slice House**, a small full-stack pizza ordering
app (React + TypeScript frontend, Express + TypeScript API).

Start here: **[LEARNING_PLAN.md](LEARNING_PLAN.md)** — 14 progressive modules covering end-to-end
UI testing and API testing, each with its own exercises and reference solutions under `tests/`.

## Quick start

```
npm install
npx playwright install
npx playwright test tests/exercises/00-setup --project=chromium
```

See [LEARNING_PLAN.md](LEARNING_PLAN.md) for the full module map and how the repo is organized.
